# Cisco ASIC Verification Internship Preparation

A structured study repository for students preparing for ASIC Verification internships, especially the Cisco ASIC Engineer Internship.

---

## Study Roadmap

### Phase 1 – Core Digital Design

- Logic Design
- Combinational Circuits
- Sequential Circuits
- FSM Design

### Phase 2 – RTL Design

- Verilog Fundamentals
- Coding Style
- FSM Coding
- HDLBits Practice

### Phase 3 – Verification Fundamentals

- SystemVerilog
- OOP
- Constraints
- Arrays
- Fork/Join

### Phase 4 – UVM Basics

- Sequence
- Sequencer
- Driver
- Monitor
- Scoreboard

### Phase 5 – Interview Preparation

- ASIC Interview Questions
- Timing Concepts
- MCQs
- Common Verification Concepts
